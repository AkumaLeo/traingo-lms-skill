# 验证说明

## 发布前可重复执行

```bash
python -m unittest discover -s tests -v
python scripts/traingo_watch.py --help
python scripts/extract_course.py --help
```

测试应覆盖课程身份错误、考试拒绝、进度完整性、完成标记隔离、停滞和运行上限，以及PDF魔数、页数不符、文件名安全、覆盖保护、失败时清理和签名URL脱敏。具体测试结果以实际命令输出为准，当前发布版未部署 GitHub Actions；README不写未经核实的固定测试数量。

## 验证等级不能混淆

- 单元测试：构造的安全快照、临时PDF和模拟浏览器返回，用来测试代码，不是平台实况。
- 本地浏览器夹具：验证真实JS执行、DOM读取和下载链路，但不证明真实企业课程授权/计时/完课。
- 真课程只读探测：证明绑定了使用者的确切已登录课程，仍不等于开始学习。
- 真学习启动：三个时间点、跨两个轮询间隔，进度或倒计时确实变化。
- 完课：明确在线章节全部100%，有逐课程安全记录；考试仍跳过。
- 导出：每份PDF实际页数等于该查看器声明页数，并做首末页可见核对。

公开版不依赖作者私有账号，CI不访问真实课程，不能将这些本地测试标注成“在所有企业平台实测通过”。遇到平台改版、CORS、账号策略或身份验证要求，停止并明确报告未完成范围。
