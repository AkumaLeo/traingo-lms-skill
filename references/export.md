# 课件导出：为什么不能抓几个缩略图就结束

Traingo文档查看器通常虚拟化渲染，只把当前附近几页放入 DOM。`document.images.length`、懒加载缩略图或 Performance 资源条目不能作为总页数依据。

已验证的定位方法是：从 `#app` 的 Vue3 根组件遍历渲染子树，仅在名为 `Photo` 的组件读取 `props.src`、`props.pages`。不要序列化整个组件、store 或 setupState，以免混入认证数据。

导出脚本对当前明确的文档执行浏览器内授权获取，真实链接留在页面内存，按块取回 PDF 字节，结束时清理临时缓存。它不使用浏览器外 Cookie、Authorization 或模拟登录。跨域不允许读取时停止，不修改 CORS、不使用浏览器启动参数关闭安全机制。

下载成功后至少需要：

1. PDF 魔数正确，不是登录HTML或JSON错误。
2. PyMuPDF可打开、未加密阻止阅读。
3. 真实页数和组件声明的总数相同。
4. 文件名来自确切课程/章节标题并处理路径非法字符；不存在路径穿越或同名覆盖。
5. 原始文件与安全manifest分别原子保存（不是两文件事务）；manifest仅记录不带认证信息的校验结果。若侧车写入失败，可能只留下已验证PDF，应检查同名侧车后重新运行；相同内容可幂等恢复，不得把缺少manifest的文件对报为完整交付。
6. 代理渲染首末页做可见内容核对；单元测试不能替代这一步。

若一个课程有多份文档，代理先保存目录清单，逐章打开和提取，每份独立校验，最后按清单核对完整数。下载动作可能产生少量浏览进度；恢复最早未完成章之后，仍须按真实时间学习。

下载总预算默认 900 秒，可用 `--timeout` 在 1–1800 秒内调整；浏览器 fetch 单次最多 120 秒，内存缓存随预算有界过期。文件默认上限 80 MiB，硬上限 100 MiB。传输期间正常学习进度变化不会被当成文档更换；课程、章节、源文档和页数仍须保持一致。

当前不提供解密/破解、整站爬取、视频去DRM或不可访问资源下载。若只能官方导出，使用官方路径；若仅可查看，未经许可不做批量重建。
